Original human-readable animation and content source files are provided for future editing.
The complete standalone, offline-ready page is ../index.html, which uses compiled assets/portfolio.js.
To make behavioral changes, edit the original source with Vite + npm packages (gsap, three, lenis),
then rebuild and reapply site additions, or edit the compiled browser JS if necessary.
For styling edits to the current ready website, use ../assets/style.css and ../assets/company-footer.css.
Bootstrap 5.3.6 is vendored in ../vendor/bootstrap and does not require an internet connection.
